## IRON NEST WEB APP
browser based proof of concept version of steam game "Iron Nest" and you act as a soldier operating a cannon and putting in bearing and explosive payload to eliminate foes
realized halfway through that I had too little time and spent less time on css

to get to the main page you have to enter a random name that also get updated to the leaderboard tab

## Technical Achievements
- **HTML Forms**: The application uses HTML form controls to allow the user to enter/select information used when launching an attack.
- **Results**: is shown by the /leaderboard page which exposes the appdata in storage
- **Form/Entry**: is shown by the game page which sends info to the server through the forms oj the side and that leads to the server processing the data and returning the coordinates where you hit
- **Server Logic**: shown by the server return the derived fields newX and newY which are derived from the previously given variables and is displayed in the left side
- **Derived field**: the new y and new x fields
- The first form is a firing form that is sent to the server
